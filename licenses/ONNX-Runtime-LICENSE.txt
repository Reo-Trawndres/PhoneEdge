ONNX Runtime 1.30.0 (https://github.com/microsoft/onnxruntime), by Microsoft.

PhoneEdge includes ONNX Runtime's .NET API (Microsoft.ML.OnnxRuntime.dll, from the Microsoft.ML.OnnxRuntime.Managed package on
nuget.org) for Talk back's voice on this PC. Its native engine (onnxruntime.dll) is not included: it is fetched only when you
download that voice (Settings > Voice & AI > Talk back > Voice on this PC), unmodified, out of Microsoft's official
Microsoft.ML.OnnxRuntime 1.30.0 package on nuget.org, checked against a pinned SHA-256, and kept per user in
%LOCALAPPDATA%\PhoneEdge\addons\onnxruntime. The notices of the third-party code built into it are in that package's
ThirdPartyNotices.txt (https://github.com/microsoft/onnxruntime/blob/v1.30.0/ThirdPartyNotices.txt).
